### 1. Proposed System Architecture Overview

The system aims to move beyond a basic passive LLM script into an Autonomous AI SOC Agent capable of handling Tier-1 and Tier-2 triage:

1. Engine 1 (Fast Noise Filter):
   - Fast ML Model (Random Forest / LightGBM) to drop obvious false positives and high-volume background noise in under 0.1 seconds.

2. Engine 2 (Autonomous Investigator & Decision Engine):
   - LLM: Powered by Gemini 3.1 Pro / LLaMA 3.
   - Advanced RAG Pipeline: Hybrid Search (Vector + Sparse BM25 via Qdrant/ChromaDB) with a Cross-Encoder Reranker to match current alerts against historical incidents and standard playbooks.
   - GraphRAG: Mapping entities (User -> Host -> IP -> Process Tree) to preserve relationship context across security alerts.
   - ReAct Agentic Workflow: Active tool-calling (VirusTotal, Active Directory lookup, EDR process tree query, Firewall rules) so the agent can actively gather evidence rather than just read raw logs.
   - Dynamic Memory Loop: Human analyst feedback (Approve/Reject/Modify) gets vectorized and ingested into long-term vector memory, allowing the system to learn continuously over time.
   - Safety & Guardrails: Strict IP logic boundaries (Internal vs. External handling), confidence thresholding (<85% confidence requires human sign-off), and human-in-the-loop (HITL) approval for destructive response actions.
